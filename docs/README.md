首个Windows预览版的安装、试用范围和限制见[alpha说明](14-alpha-release.md)。
系统依赖复用、最低版本和PostgreSQL用途见[依赖与兼容](15-runtime-compatibility.md)。

## 当前文档与实现

仓库已有产品核心、Hindsight适配、方法学习与管理、样例Connector和效果回顾。实现计划区分未接完的功能、已知质量失败和待验收项；[运行记录](research/2026-09-14-implementation/README.md)保留实际结果及限制。字段或探针存在不能证明相应能力通过。

开发期没有需要保留的旧用户数据，旧开发布局迁移不列入首版待办。方法迁移或任务迁移指把学到的方法用于较晚的新任务，仍须验收。页面不另建工作流执行器，宿主采集与回填优先复用官方模块。

[evals](../evals/README.md)说明实际开发材料及限制，[probes](../probes/copilot/README.md)说明可运行宿主检查。当前文档不保留Mem0专用实现作为待办。
