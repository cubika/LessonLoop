# 方法库与使用体验

日期：2026-09-15。状态：当前UI、CLI与导出设计，主要入口已有基础实现，完整操作与宿主关联的差距见[13](13-implementation-plan.md)。数据见[07](07-storage-model.md)，调用见[04](04-contracts-and-extensions.md)。

## 方法库首页

主要内容入口是方法库（Playbook）、经验（Experience）和来源（Source）。来源页合并原文提交、查看与控制；经验和方法详情按需展开相关工作记录。效果回顾是事件视图，不提供独立案例的创建或编辑入口。

首页按工作主题组织方法，例如接口变更、性能排查和发布检查。方法卡显示名称、目标、主要适用范围、使用状态和最近变化。用户可固定常用方法，按主题、项目条件、可用性和关键词查找。

方法库优先展示用户可做的事和具体变化，L1–L5用于展开学习依据，不把最高层级放在所有结果最前。复盘中、需要新信息和处理失败属于作业状态，方法未更新时不显示虚假的成长。

输入入口支持工作片段、案例文件、资料和指定主题复盘。用户无需先手工填完整方法，材料有价值时系统自动形成可用做法，普通输入可零产出。

## 方法详情

| 区域 | 内容与操作 |
|---|---|
| 用途与范围 | 要解决的问题、全局条件、明确例外、有效时间 |
| 做法 | 有序步骤、结果依赖的分支、何时停止或求助 |
| 完成检查 | 当前路径要检查哪些实际结果 |
| 依据 | 支持经验、来源短摘录、工作案例与未决解释；分层展开L1–L5 |
| 变化 | 最近修订改变了哪些步骤和原因，可比较仍保留的旧版 |
| 使用情况 | 投递、采用、结果及用户反馈各自已知程度 |

界面不要求用户认识bank、内部ID或原生分数。没有单一成熟度百分比，层次、依据和本次适用性分别表达。缺失旧依据或已到期案例显示缺失，不用当前文本冒充历史。

## 在任务中使用

自动推荐开启时，Agent在新任务开始搜索方法并获取最相关一项的完整指导。Agent核实全局条件，按步骤取得实际结果并选择分支；没有合适方法照常工作。使用过程中无需向服务逐步上报完成或申请后续步骤。

用户可在详情选择“用于当前任务”，或在Agent中直接指定方法。客户端绑定方法修订和任务，调用preparePlaybook；宿主无法关联任务时提供方法引用或导出，不显示已投递。UI不另起一个工作流执行器。

页面承担方法查看、编辑、选择和状态反馈。实际观察与步骤结果由Copilot工作过程捕获，供后台学习和回顾；首版不要求用户在页面逐步勾选或手工驱动分支。官方管理组件可复用，产品读写须接到核心。当前页面可选择核心列出的活跃宿主任务，并复制含方法修订及使用引用的结果；准备成功仍不冒充宿主已投递。

步骤准备只提供指导。命令、写文件和外部操作仍遵守原任务权限，方法不授予授权。新信息改变条件时由Agent重新判断适用性；需要核对方法当前版本时再次获取；跳过一条方法不删除其在其他场景的价值。过长视图可显式展开，完整限制放不下时不提供残缺的可执行步骤。

基础接入只承诺注入和显式准备时的当前性，可关联工具步骤的宿主才额外提供步骤前刷新。已进入模型上下文的文本无法撤回，这个限制在诊断中表达，不用模糊“实时同步”承诺代替。

## 方法更新与控制

自动学习在已授权范围内提出并发布合格变化，变化说明要指出具体动作，例如新增扩展区分支或调整检查顺序。没有新信息的正常复用不制造版本。用户设置的持续要求由独立控制保存，新案例不能自行覆盖。

用户可修改目标、步骤或例外，停用、删除方法，或把仍保留的旧版内容作为新修订重新评估。恢复不撤销后来发生的删除、撤权和忘记。拆分方法保留各自范围和前身引用，不留下未解释的冲突建议。

明确纠正显示可靠接收、旧版暂停、新版生效的实际状态。快速完成合并一次回执，慢任务更新同一项；界面关闭不取消已接收学习。普通方法更新不逐条打断会话。

## CLI

以下为目标命令组，部分已有开发入口；当前可运行命令以[README](../README.md)和CLI help为准。CLI与UI调用相同产品API，参数按04核对。

| 命令组 | 用途 |
|---|---|
| lessonloop source submit/show/append | 提交、查看来源片段，补充同一工作的结果 |
| lessonloop source work / experience work / playbook work | 按需展开相关工作记录 |
| lessonloop experience list/show/verify | 查看经验与补充依据 |
| lessonloop review topic / job show | 发起主题复盘或查询学习作业 |
| lessonloop playbook list/show/history | 查找方法、查看步骤及版本变化 |
| lessonloop playbook prepare | 为任务获取完整指导 |
| lessonloop playbook revise/state/remove | 修订、停用或删除，核对当前版本 |
| lessonloop playbook export | 导出指定修订的可审阅快照 |
| lessonloop playbook usage | 按需查看该方法的使用记录 |
| lessonloop report list/configure | 查看效果回顾并管理回顾和通知 |

默认中文界面不强制存储语言。翻译显示不改原文引用或自动产生新修订。安装、运行和引擎诊断命令由[10](10-distribution-and-installation.md)说明。

## 导出方法与 Skill

首版提供Markdown、checklist和Skill文件快照。导出包含方法ID/revision、生成时间、目标、范围、步骤/分支、完成和停止检查，以及允许导出的来源。外部格式容不下必要限制时分成明确引用的资源或报不支持，不静默截断。

Skill是一种方法表示，不是自动执行许可。导出不安装到宿主、不修改全局指令、不运行命令；用户之后使用仍需任务权限与当前条件检查。存在私有来源时先选择导出范围并预览脱敏内容。

快照不会随着原方法更新或删除自动变化，文件说明其版本与检查当前状态的方式。断开服务时不能声称仍为最新。受管理的Skill安装、同步和撤回不在首版范围。

## 页面验收

以同一案例族贯穿输入、方法生成、查看、任务准备、结果补充、方法变化和导出，执行MTH01–MTH12。不能仅用预填卡片证明学习能力，不能用原生Control Plane替代产品方法操作，也不因展示方法卡就判定真实采用。
