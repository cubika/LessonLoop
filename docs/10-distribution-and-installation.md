# 本地发行与运行

日期：2026-09-15。状态：首个Windows alpha发行准备，安装/配置/诊断、自启、卸载和受控清理已有实现；预览范围与使用方式见[alpha说明](14-alpha-release.md)，正式质量门槛保持未通过。

## 发行目标

提供面向个人的方法学习服务：方法库UI、CLI、后台核心、官方接入适配和Hindsight。首个目标为Windows x64、普通用户、Windows PowerShell 5.1或PowerShell 7，不要求Docker；缺少Node、Python或数据库时，安装器先征求安装确认。

用户已有Copilot CLI作为工作宿主，学习推理使用同用户的现有Copilot订阅。Hindsight与数据自托管，嵌入/重排使用独立本地组件；云端推理不能描述为完全离线。没有登录或宿主时可以安装，但需明确待配置，不能报告完整就绪。

Python、Node与PostgreSQL优先复用达到最低版本的已有安装，过旧时确认升级，缺失时确认安装。外部宿主版本区分已测与未测，见[兼容说明](15-runtime-compatibility.md)。

## 组件与官方工具

| 组件 | 发行责任 |
|---|---|
| Bootstrap和安装管理器 | 固定版本下载、校验、目录归属、安装锁和激活 |
| LessonLoop核心、UI、CLI | 方法学习、使用、用户控制与回顾，调用同一产品API |
| AgentAdapter | 固定官方模块与必要修改、宿主注册、产品MCP及能力诊断 |
| Hindsight | 官方引擎与适配器，原生管理UI/CLI供维护诊断 |
| 私有数据库 | 复用兼容PostgreSQL程序及检索扩展，DataRoot独立，产品与原生独立schema |
| 模型组件 | 官方provider认证及独立本地多语言嵌入/重排 |

复用官方组件不等于允许其自行扫描历史、下载运行时或自动升级。发行清单记录上游版本/提交、局部修改、许可和宿主兼容范围；关闭与产品固定版本及授权不符的默认行为。

原生Control Plane不能作为修改产品方法的旁路。用户已有独立插件不静默卸载；doctor发现同一工作路径存在未经控制的原生注入时报告冲突，不宣布接入完整。

## 安装与首次设置

alpha已有固定版本PowerShell安装入口，见[安装说明](14-alpha-release.md)。安装过程为：获取锁与平台检查 → 下载清单和组件 → 校验并解包到staging → 基本自检 → 初始化当前格式数据 → 健康检查 → 激活稳定入口 → 注册用户选择的Agent。

setup分别配置模型、scope和来源范围、工作学习、自动推荐、效果回顾与提醒。历史导入需要明确范围；不默认导入全部会话或git历史。长期证据保留与原生副本策略说明后保存配置，预算由实际profile决定。

安装状态为ready、installed_needs_setup、failed，分别使用0、2、1退出码。模型、数据库、核心和宿主状态分别报告；非交互模式不无限等待登录或接受新条款。插件失败时可保留已安装核心，重试不产生重复注册。

## 运行与命令

| 命令组 | 用途 |
|---|---|
| lessonloop setup / status / doctor | 配置、组件和能力诊断 |
| lessonloop start / stop / restart / ui | 管理后台及打开产品界面 |
| lessonloop agent install/remove/status | 管理宿主接入，不改变记忆引擎或共享登录 |
| lessonloop model configure/status | 模型provider配置 |
| lessonloop memory status | 引擎能力及当前数据版本 |
| lessonloop autostart enable/disable | 当前用户登录自启，默认关闭 |
| lessonloop update / rollback | 固定版本激活和兼容回退 |
| lessonloop uninstall / data purge | 移除程序或单独清理指定受控数据 |

方法、来源、复盘和报告命令由[12](12-method-library.md#cli)维护，当前开发入口以CLI help为准；已安装launcher的命令见[14](14-alpha-release.md)。普通UI、CLI和Agent访问相同核心，不各自创建独立数据库或后台实例。

后台管理器以隐藏窗口和当前用户身份管理数据库、引擎、核心与本地模型。关闭终端或UI继续工作，关机/注销不处理任务；默认不创建高权限系统服务。每个DataRoot只允许一个管理实例。

## 文件与进程所有权

InstallRoot默认在LOCALAPPDATA/LessonLoopRuntime，DataRoot在LOCALAPPDATA/LessonLoop。bin保存稳定launcher，versions和components保存固定程序，staging保存未激活内容，active.json原子指定当前版本。DataRoot分开config、storage、run、logs/cache和受控backups。

所有路径从安装记录解析，支持中文和空格。拒绝绝对路径解压、上跳和链接逃逸；递归移动/清理前核对规范化路径、安装身份和归属。自定义安装目录保存稳定定位，不在默认位置悄悄建立第二实例。

已有合格运行时直接复用；Python/Node升级需确认后交给官方安装器，其PATH和权限行为由该安装器决定。PostgreSQL不接管现有数据库服务。进程归属由安装ID、DataRoot、可执行路径、PID及启动时间共同确认，不按进程名批量终止。

核心仅监听loopback且认证，原生引擎和数据库只提供必要本地访问。秘密保存在当前用户凭据设施，URL、命令行和日志不含凭据。Copilot/gh共享登录不属于安装器，不复制、清除或带入发行包。

## 组件构建

主发行包包含核心、Node应用依赖、脚本和模型清单，模型在安装时按需下载并校验，升级复用旧文件；PostgreSQL作为可选组件单独打包。Hindsight等Python应用依赖在安装时从PyPI下载wheel到产品.venv，不编译源码。清单列组件URL、大小、摘要、许可、schema和协议兼容范围，运行时不追踪main/latest。

先构建组件与manifest，再生成引用清单摘要的bootstrap，避免清单自哈希循环。测试实际发布字节，验证干净Windows无管理员安装、登录缺失、断网启动、依赖兼容、中文检索及组件健康。发行支持以实际结果为准，官方源码可运行不等于本产品已有可分发包。

若默认免费自托管Windows配置不成立，停止发布并重审，不能静默改成付费云服务、要求手工Docker或切换后端后继承结果。

## 升级、恢复与卸载

开发期没有旧用户数据，首版不交付旧开发布局或旧原型转换工具。当前只支持声明兼容的程序版本切换；数据结构或引擎组件不兼容时明确拒绝。未来需要支持这类升级时，再单独定义并实现数据转换。当前格式的备份、恢复及控制保留仍须验收。

更新由用户选择固定版本触发。准备新组件时旧服务可继续，切换前停止新输入、排空或持久化在途作业；unknown原生写未核实则阻止版本切换。备份覆盖产品对象、用户控制、来源、原生数据和必要配置，不能只复制向量或活跃数据库目录。

新版本健康和数据兼容确认后激活。开放新写之前失败可按兼容快照回退；接受新数据后回滚必须保留后来的删除与纠正，不兼容则修复或向前迁移。旧MCP进程需要重载时明确报告，不承诺热切换。

普通卸载停止归属确认进程、移除本产品注册和程序，保留数据及恢复所需凭据；用户改过的配置只移除本产品条目，不覆盖整文件。文件被占用时明确残留，同版维护入口可重试。

永久清理是独立操作，明确DataRoot和受控备份后确认。先阻断写入、自启和缓冲重放，再清理核心、原生、投影、历史、回顾及备份，逐项确认；不删除工作目录、共享账号、其他数据库或用户另存导出。操作期间归属或占用无法确认就停止，不报告完成。
