# Repository instructions

- Create and switch to a new `codex/` branch before changing code or documentation. Keep development commits off `main`.
- If changes were started on `main`, move the uncommitted work to a new branch before continuing. Preserve unrelated local changes.
- Run the relevant tests and checks on the development branch. Merge into `main` only after validation passes; report unresolved failures instead of merging.
- Keep the development branch until its commits have been merged.
